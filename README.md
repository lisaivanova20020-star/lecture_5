
# Time Tracking

**Практическое задание к лекции № 5 «Этапы разработки программного продукта».**

## Назначение проекта

Модуль учёта рабочего времени для системы управления задачами. Позволяет запускать и останавливать таймеры, подсчитывать затраченное время и формировать отчёты по задачам и пользователям.

## Файлы

| Файл | Содержимое |
|---|---|
| `task_system.py` | Система управления задачами |
| `time_tracking.py` | Модуль учёта времени |
| `test_time_tracking.py` | Модульные тесты |

## Основные классы

- `TimeEntry` — хранит интервал работы над задачей.
- `TimeTracker` — управляет таймерами и формирует отчёты.
- `TimeTrackedTaskManager` — интегрирует учёт времени в систему задач.

## Основные возможности

- Запуск и остановка таймера.
- Подсчёт общего времени по задаче, включая несколько запусков.
- Формирование отчётов по задачам и пользователям.
- Обработка ошибок с помощью `ValueError`.

## Пример отчёта

```python
{
    'total': '00:45:00',
    'by_task': {'REST API': '00:45:00'},
    'by_user': {'Алексей': '00:45:00'}
}
```

## Тестирование

Запуск всех модульных тестов:

```bash
python3 -m unittest -v
```

Тесты проверяют работу таймеров, подсчёт времени, формирование отчётов и обработку ошибок.

Для тестирования используется `FakeClock` — имитация системного времени, позволяющая проверять работу программы без ожидания реального времени.

## Демонстрация

Отдельный запуск демонстрационного примера:

```bash
python3 time_tracking.py
```

Программа создаёт задачу `REST API`, пользователя `Алексей`, имитирует 45 минут работы и выводит отчёт с затраченным временем.
