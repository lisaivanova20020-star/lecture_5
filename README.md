
# Time Tracking

**Практическое задание к лекции № 5 «Этапы разработки программного продукта».**

## Назначение проекта

Проект представляет собой модуль учёта рабочего времени для существующей системы управления задачами.

Основная цель проекта — предоставить пользователям возможность отслеживать время, затраченное на выполнение задач, учитывать общее время работы и формировать отчёты по затраченному времени.

Модуль интегрируется с существующей системой задач без изменения её базовых классов, расширяя функциональность системы.

## Файлы

| Файл                    | Содержимое                           |
|-------------------------|--------------------------------------|
| `task_system.py`        | Существующая система задач из лекции |
| `time_tracking.py`      | Модуль учёта времени                 |
| `test_time_tracking.py` | Unit-тесты                           |

## Требования и реализация

| № | Требование                           | Реализация                                             |
|---|--------------------------------------|--------------------------------------------------------|
| 1 | Старт и остановка таймера для задачи | `start_timer(task_id, user_id)`, `stop_timer(task_id)` |
| 2 | Учёт общего затраченного времени      | `get_task_time(task_id)`                               |
| 3 | Генерация отчётов по времени          | `generate_report()`                                    |
| 4 | Интеграция с системой задач           | `TimeTrackedTaskManager` — наследник `TaskManager`     |

## Основные классы

- `TimeEntry` — хранит один интервал работы пользователя над задачей.
- `TimeTracker` — запускает и останавливает таймеры, суммирует временные интервалы и формирует отчёты.
- `TimeTrackedTaskManager` — подключает трекер к существующей системе задач без изменения её базовых классов.

Для обработки ошибок используются исключения `ValueError`. Они возникают, если задача или пользователь не найдены, таймер уже запущен либо таймер не был запущен перед остановкой.

## Пример использования

```python
from datetime import datetime, timedelta
from task_system import Priority
from time_tracking import TimeTrackedTaskManager

manager = TimeTrackedTaskManager()

user = manager.create_user("Алексей", "alexey@company.com")

task = manager.create_task(
    "REST API",
    "Описание",
    Priority.HIGH,
    datetime.now() + timedelta(days=7)
)

manager.start_timer(task.task_id, user.user_id)

# Выполнение задачи

manager.stop_timer(task.task_id)

# Получение общего затраченного времени
print(manager.get_task_time(task.task_id))

# Формирование отчёта
print(manager.get_time_report())
```

Пример результата отчёта:

```python
{
    'total': '00:45:00',
    'by_task': {'REST API': '00:45:00'},
    'by_user': {'Алексей': '00:45:00'}
}
```

## Тестирование

Для запуска модульных тестов необходимо выполнить команду:

```bash
python3 -m unittest -v
```

Тесты проверяют:

- корректность запуска и остановки таймера;
- защиту от повторного запуска таймера;
- обработку попытки остановить незапущенный таймер;
- обработку отсутствующих задач и пользователей;
- подсчёт общего затраченного времени;
- суммирование нескольких временных интервалов по одной задаче;
- учёт времени работающего таймера;
- формирование общего отчёта по задачам и пользователям;
- корректность форматирования времени;
- совместимость с существующей системой управления задачами.

**Особенность тестирования:** используется `FakeClock` — имитация системного времени, которая позволяет проверять работу таймера без ожидания реального времени. Это делает тесты быстрыми и предсказуемыми.

После выполнения всех тестов дополнительно выводится демонстрационный отчёт с задачей `REST API` и пользователем `Алексей`.

## Демонстрация работы программы

Для отдельного запуска демонстрационного примера необходимо выполнить команду:

```bash
python3 time_tracking.py
```

В этом режиме программа самостоятельно создаёт пользователя и задачу, запускает таймер, имитирует 45 минут работы, останавливает таймер и формирует отчёт.

Ожидаемый результат:

```python
{
    'total': '00:45:00',
    'by_task': {'REST API': '00:45:00'},
    'by_user': {'Алексей': '00:45:00'}
}
```

Таким образом, программа поддерживает два способа запуска:

1. `python3 -m unittest -v` — запуск всех модульных тестов с последующим выводом демонстрационного отчёта.
2. `python3 time_tracking.py` — отдельный запуск демонстрации работы модуля учёта времени.
